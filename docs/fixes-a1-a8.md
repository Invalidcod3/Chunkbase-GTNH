## 校准与回归

- 439 项 Node 自动测试、13 项 Python 工具测试、108 个静态文件语法及引用检查通过。完整包已重建；4175 预览的页面、入口脚本、包目录和新增模块均返回最新文件。

- 扩展维度：150 组、115,200 像素；90 组结构、7,182 个标记全部匹配。新增小行星部分为 15 组、184 个标记（146 个空心小行星、38 个兼容基地起点）；分割线采用非整齐坐标，拆分与整体查询一致。
- 出生点：5 个种子与原 Worker 相同，包含超出 JavaScript 安全整数的种子及正负 long 极值。最大 long 种子经过一次尝试得到 -11,-35；另有模拟测试覆盖 1,000 次上限、取消和缓存复用。
- 资源：252 组、41 维度、18,375 矿脉、1,804 流体田/115,456 区块初始产量一致。
- 旧结构复核：15 组、99 个刷怪笼候选；20 组、1,079 个 Roguelike/神秘时代结构一致。主世界底图取样、暮色分批和旧结构路由验证继续通过。
- 新回归覆盖包故障隔离、色板原子注册、失败瓦片重试保留成功数据、精确资源筛选先于上限、流体最佳区块边界、导出取消不再发起后续批次、要塞导航一致、偏好损坏和环境隔离、本地 HTTP 模块及目录边界。

## 仍属后续范围

这些修复不等于与桌面版所有功能完全等价。存档/玩家/游戏连接、读取实际生成状态和写入游戏仍是此前明确排除的后续阶段。任意 GTNH 版本自动采集适配、JourneyMap 在目标游戏中的实际导入，以及鼠标触屏/移动端/高 DPI/长时间操作仍需专项验收；本次数值与代码测试不代替浏览器视觉验收。
