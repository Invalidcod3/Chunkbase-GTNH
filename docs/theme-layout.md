# Chunkbase NH 主题移植（2026-09-16）

宽屏布局以用户的 `ChunkbaseNH网页.ai` / PDF 为参考，复用所提供的 NH 标志、两套字体和 SVG 控件。AI 中隐藏的“筛选菜单打开按钮”用于折叠态参考；按用户后续要求，不照搬隐藏的“下拉菜单”设计图层。源设计文件不作修改。

## 已确认的交互

- 维度和图层为单选下拉菜单，文字左侧显示图标。图层分为兴趣点、矿脉、流体矿脉，筛选内容随之切换。
- 菜单互斥展开，选择、点击外部或 Esc 时关闭；支持方向键、Home/End、Enter 和键盘文字检索。展开、收起使用短过渡，遵循系统减少动态效果偏好。
- 筛选项高亮表示显示，未高亮表示屏蔽。兴趣点保留原复选框逻辑；资源新增多项屏蔽并保留名称、材料、高度和产量条件。资源屏蔽条件同时应用于显示、点击命中和导出扫描。
- 分类支持展开与收起；筛选面板折叠后不保留整条侧栏，只在地图右上角显示源稿中的按钮。
- 折叠按钮距地图右侧和顶部各 16px。矿脉、流体列表底部的存档说明已移除；缺少数据等实际状态仍会提示。
- 生物群系筛选沿用 Amidst `BiomeSelection`：默认关闭高亮且无选中项，可先选群系再启用；关闭后恢复全部原色。选中行高亮，未选中群系按 `BiomeColor` 的 `(channel + r + g + b) / 30` 整数公式变暗。全选／全不选与 Amidst 一样作用于完整选择集合，新遇到的群系也遵循此默认值。
- 生物群系支持名称搜索、颜色标识及环境隔离的选择记忆。列表优先显示当前维度的已注册目录或固定群系；未提供独立维度目录的函数包使用包目录。CPU/GPU 共用配色逻辑，不更改群系样本、查询或导出数据。
- 维度图标使用 GT5 `gtneioreplugin` 的 top/front/right 贴图，按 Amidst `ProspectingTextures.dimensionIcon` 的原始仿射变换合成为 32px 透明底立体图标，覆盖当前 42 个维度。
- 浏览器标签页图标复用页面的 NH 矢量标志。
- 矿物筛选使用对应矿物的立体贴图，流体筛选使用平面流体首帧。小行星矿脉的地图标记和选中详情复用对应矿物贴图；颜色后备仅用于未收录或加载失败的资源，不修改生成结果。当前素材目录覆盖 549 个维度矿物条目、48 个维度流体条目，去重后为 145 组贴图。
- 暮色森林的筛选项、地图标记和详情使用同一组 `twilight_feature_*.png`，兼容地图 subtype 与筛选类型两种键。
- Roguelike 地牢按桌面端 `GtnhRoguelikeDungeonType` 拆成沙漠、森林、冰原、丛林、恶地、山地、平原、沼泽八个独立筛选项，显示类型名称、对应图标和各自数量，不显示括号内的入口说明；支持该结构的环境保留零数量选项。地图显示与导出共用 subtype 筛选键，旧的整类隐藏设置恢复为八类全部隐藏。
- 矿物名称与材料组合对照 Kiwi233/Translation-of-GTNH 固定版本 `d2635d9e7137f7886ad29f9d20c8b445cefa9e09`，当前提取 247 条材料名称。筛选、地图标签、详情共用显示转换，中英文搜索在截断扫描结果前匹配；原始 ID、预测数据与保存的筛选集合不变。上游仍为 `BArTiMaEuSNeK` 的专有名称保留原文。来源、具体材料键和许可随附于 `dist/i18n/`。
- 更新语言数据：运行 `tools/fetch-resource-translations.ps1` 获取固定版本语言文件，再运行 `node tools/import-resource-translations.mjs` 提取当前环境用到的词条。遇到没有语言键的英文矿物时导入会报错，避免静默遗漏；已有中文名称若无法匹配则保留原文。
- X/Z 显示地图中心。双击数值或键盘 Enter/F2 进入编辑，回车定位，保留另一轴的当前位置；Esc 或失焦取消。数值输入没有增减箭头。
- 放大、缩小、回原点和比例尺沿用原地图实现。比例尺的实际线宽由地图计算，不被 CSS 截短。
- 选中信息参考 `SelectedIconWidget` / `WorldIcon.toString`：24px 图标、名称及 `[X, Z]`，深色半透明背景、自适应内容宽度。补充信息收进省略号，复制坐标功能保留。
- 左上角常驻的维度名称/底图说明框不显示；移除前往要塞入口和底部“本地计算”文字；暂时隐藏坐标导出和 PNG 导出入口，内部导出实现仍保留。
- 设置面板沿用网页深色配色，仅显示 GPU 加速（含当前档位说明）、计算并行度（含自定义线程数）、算力分配、平滑拖动和平滑地图图像。其他旧设置和诊断节点置于隐藏且不可交互的容器内，保留原有初始化依赖；状态刷新不会重新显示这些内容。窄屏仅基础换行、面板覆盖和默认折叠，等待独立设计。
- 信息面板与设置面板共用深色样式，移除 NOTICE 页面入口与底部存档支持说明；源码入口为 `https://github.com/Invalidcod3/Chunkbase-GTNH`，保留 GPL 许可入口。原维度支持表格上方新增制作人员表格，网页作者由维护者确认署名 InvalidCode，Amidst 原作者按桌面端关于窗口署名 Skidoodle（skiphs），另列 GTNH 适配、整合包、模组与汉化贡献。两张表格及标题随中英文切换。

## 维护与预览

`dist/theme.css` 控制本轮主题、设置与信息面板配色。`dist/theme-ui.js` 管理图标菜单、展开状态、资源复选和坐标编辑，`dist/app.js` 继续负责世界数据及原交互。

`node tools/sync-preview-ui.mjs` 将本轮界面与筛选文件同步到已经构建好的 `private-packs/rwg-local-preview/`，不替换函数包、环境配置和校准记录。此命令只更新预览目录，不重建私有 ZIP。随后使用 `node tools/serve.mjs --rwg-preview` 预览；可通过 `PORT` 指定端口。

素材已包含在 `dist/assets/ui/`，正常构建无需访问原设计目录。`tools/import-ui-design.py` 仅用于从本机原稿重新提取素材，需要 pypdf；原稿目录在脚本中显式指定。

## 验证

自动测试覆盖单轴坐标输入边界、保留另一轴的分数位置、资源多选在截断前过滤以及流体导出一致性；原测试套件一并运行。

浏览器检查了维度/图层选择、键盘导航、菜单互斥、资源全选/全不选、单项显示、侧栏折叠、坐标提交/取消/回原点、结构信息框和原设置/信息对话框。检查了 1920px 宽屏布局及 390px 窄屏基本宽度；不代表专门的移动端验收。
