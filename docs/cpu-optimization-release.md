# CPU 热点替换与验证

已将火焰图实验中的两项等价优化接入正式编译流程，并更新本地完整预览包。原始生成代码保存在各编译目录的 `selection.unoptimized.js`；构建检查输入、输出和优化器的 SHA-256，旧校准报告无法用于新代码打包。

## 实现

- RWG、暮色、扩展维度和洞穴引擎分别折叠 18、29、273、10 处固定长整数构造，预先生成等价 BigInt 常量，减少随机数生成链中的反复构造。
- RWG 的 CellNoise 多项式最终仅取低 31 位，改用 `Math.imul` 精确计算所需位。完整种子先以 BigInt 提取低 32 位再转 Number；没有把一般 64 位算法降成浮点数，也没有近似噪声或地形高度。
- 暮色以及配置中使用 GenLayer 图的扩展维度直接生成完整瓦片。原来的半分辨率预览仍需生成近似相同的底层区域，跳过它减少重复工作。主世界及其他维度保留默认渐进流程。新区域不再有单独的粗预览，已有底图继续按原流程显示。
- 缓存实现、键、容量、淘汰规则、线程池和 GPU 算法保持原样。返回地图的采样精度不变。
- `tools/cpu-optimizer.mjs` 检查已审阅的长整数运行时及 CellNoise 函数文本；不认识的新生成形式会停止构建，要求重新审阅和校准。

## 配对测试

本机 Node v24.19.0，实际替换后的引擎对比保留的原始引擎；相同 Provider 和缓存实现，128×128 像素，起点 (-4096, 2048)，三种种子交替执行先后顺序。以下为三次耗时中位数。测量含正常计算让步，不含浏览器绘制、Worker 通信或 GPU；不是整屏首帧基准。

| 计算路径 | 间隔 | 替换前 | 替换后 | 加速 |
| --- | ---: | ---: | ---: | ---: |
| 主世界完整瓦片 | 4 | 205.1 ms | 121.4 ms | 1.69× |
| 主世界完整瓦片 | 16 | 1725.5 ms | 1073.9 ms | 1.61× |
| 暮色完整瓦片 | 16 | 265.3 ms | 124.3 ms | 2.13× |
| 下界完整瓦片 | 16 | 918.2 ms | 509.7 ms | 1.80× |
| 暮色：旧粗算+精算 → 新直接精算 | 16 | 495.7 ms | 108.5 ms | 4.57× |
| 下界：旧粗算+精算 → 新直接精算 | 16 | 1700.7 ms | 494.7 ms | 3.44× |

直接路径与加载策略路径分别独立运行，预热和缓存状态会有差别，不能将两组收益直接相乘。小查询更容易受 JIT、计时和系统调度影响。其他 GenLayer 维度通过一致性校准，但尚未逐一给出稳定速度倍率；洞穴的常量折叠也不承诺相同幅度的刷怪笼扫描提速。

原始三轮结果及引擎哈希：`.test-work/cpu-replacement/benchmark.json`。可用 `node tools/benchmark-cpu-replacement.mjs` 复测；131,072 个比较像素全部一致。
