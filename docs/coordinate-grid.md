# Amidst 风格坐标网格

地图图层中的“区块网格”已替换为“坐标网格”。依据原 Amidst `fragment/drawer/GridDrawer.java` 的步长规则以及 `Resolution.FRAGMENT` 的 512 方块基础尺度，使用 `512 × (floor(0.25 / scale) + 1)` 方块间距；`scale` 是每方块对应的屏幕像素数。

| 缩放比例 | 网格间距 |
| --- | --- |
| 0.5 | 512 方块 |
| 0.25（默认） | 1,024 方块 |
| 0.125 | 1,536 方块 |
| 0.0625 | 2,560 方块 |
| 0.03125 | 4,608 方块 |

网格交点旁显示 `X, Z` 坐标，字号固定为 16 屏幕像素，白字黑描边。拖动时网格与世界坐标同步，不跟随屏幕重设原点；负坐标与正坐标使用同一套整数倍定位，避免直接移植 Java 负余数分支产生不对称线条。

保留原项目大网格、随缩放调整和交点坐标的主要行为。Web 额外给深色网格线加淡色边缘以适应末地，并在世界边缘的长坐标可能相撞时减少标签数量，网格线间距不受影响。这是适配后的同类系统，不是逐像素复刻 Swing 绘制。

坐标网格对所有维度可用，也会出现在 PNG 中。地下流体图层的区块产量小网格独立保留。图层开关默认仍关闭，开启“坐标网格”即可使用；切换网格和平滑显示只重绘，不重启底图或标记查询。

主要实现为 `dist/map-grid.js`。测试覆盖桌面参考间距、跨零/负坐标定位、平移、远景密度及长标签避让。
