# F5–F9 修复与验证（2026-09-15）

本轮修复 [复审发现的五项问题](audit-2026-09-15.md)，保留前面的 F1–F4、RWG 精确稀疏采样和清晰底图复用。

## 修复结果

| 问题 | 当前行为 |
| --- | --- |
| F5 暮色粗算更慢 | 先批量生成有界的连续栅格，再按请求坐标取样；默认预览从 4,096 次生成器调用降为 4 次 |
| F6 结构大视野报错 | 地图及结构导出通过 `structure-query.js` 按 1,024 方块网格分批，去重、裁剪并增量显示 |
| F7 旧视野阻塞新底图 | Worker 支持按请求取消；离屏/旧缩放瓦片释放槽位，视野标记任务立即失效并中止；排队任务按底图、可见标记、显式导出的顺序处理 |
| F8 隐藏结构仍查询 | 隐藏时不再自动发起结构查询，正在运行的标记任务也取消；重新显示后查询当前视野 |
| F9 PNG 名称错世界 | 编码开始前捕获文件名，不在异步回调中读取已经改变的世界状态 |

### 暮色的批量抽样

保持 GenLayer 的原始采样坐标、quarter/full 层选择、整数取整和色板，不用插值生成群系。稀疏路径每块输入范围最多 128×32 个源像素，分块之间可以取消。完整 step=1 / step=4 路径仍按条带生成。

扩展验证还发现原 VoronoiZoom 对未对齐原点和某些矩形尺寸存在隐含要求，可能造成内部数组越界。现在 full 层的请求宽高补齐到 4 的倍数，再只取原请求范围，填充不会进入输出或改变坐标。覆盖 step=1、2、3 的非规则矩形，并与真实生成器逐点对照。

本机相同种子、三个区域的最新结果：

| 起点 X / Z | 128×128 精算 | 64×64 预览 |
| --- | ---: | ---: |
| 0 / 0 | 63.34 ms | 15.59 ms |
| 1,536 / 0 | 26.60 ms | 13.77 ms |
| −2,048 / 0 | 16.16 ms | 12.01 ms |

原审计预览耗时约 521–803 ms。两次运行存在 JIT 和其他负载差异，以上不是浏览器首屏或跨设备基准；调用次数下降和对应采样点一致均有断言验证。

### 结构分批与取消边界

单次 Provider 面积限制继续保留。分批只拆分目标输出范围，预测器内部的地形邻域、结构避让范围、RNG 消耗和生成规则不改动。去重包含种类、子类、位置及可选 Y，不把同一 X/Z 的不同标记错误合并。

地图优先中心区域，最多显示 20,000 个结构，达到上限在计数旁提示“部分结果，请放大”。PNG 保存当前显示范围，仍遵守此上限。导出按固定区域顺序扫描，在种类筛选之后应用用户数量上限，再对选中结果按坐标排序；JSON / JourneyMap 元数据携带 `selectionOrder: region-scan` 和 `truncated`。不能把截断结果解释成完整视野的最近点。

每个 Worker 请求有独立取消控制，普通平移及图层筛选不再 reset 全部任务。导出的视野及筛选在点击时固定，不受随后平移或勾选图层影响；切换种子、维度、环境仍取消旧世界的全部请求。

生成器始终串行运行，避免共享种子状态交错。取消在任务主动让出执行权后生效，不能中断正在执行的同步 JS 片段；优先级作用于排队任务，不是多线程抢占。当前没有新增导出取消按钮，也没有承诺导出在持续交互时的完成时限。
