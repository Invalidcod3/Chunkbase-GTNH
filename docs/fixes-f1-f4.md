# F1–F4 修复记录

对应 [2026-09-14 审计](audit-2026-09-14.md)。本轮保留原预测算法与每次查询的安全上限，修复前端调用与状态管理。

- **F1：资源大视野。** 地图按 1,024 方块的区域分批查询，边界对齐矿脉区块和流体田，先显示中心附近区域并逐批更新进度。地图最多保留 20,000 个资源位置，达到上限在页面明确显示“部分结果，请放大”。导出独立扫描当前视野，先应用筛选条件，再按用户数量上限提前停止；不会因为地图显示上限而只能导出已显示区域。固定区域扫描结果不是整个视野最近的若干点。旧视野或旧世界的批次不会回填，也不会继续启动下一批；已在计算的单个批次沿用 Worker 的原取消规则。
- **F2：暮色群系导出。** 对齐采样原点，维持原有完整层／四分之一层语义。JSON 的 `requestedBounds` 保留原视野，`x/z/step/width/height` 描述实际栅格，`bounds` 描述采样点范围。调整后的栅格仍受像素数量限制。
- **F3：世界状态。** 种子校验成功后，维度、种子、模式和配置统一生效并取消旧任务。失败时保留旧世界并恢复相关控件；种子输入框保留待编辑文本。环境导入不会在载入失败时误报成功。
- **F4：边界地图。** 只请求有效坐标，包含 RWG 四分之一采样的两个方块偏移。边缘瓦片按裁剪后的宽度读取群系，透明保留边界外区域；无有效像素的瓦片不启动查询。PNG 等待当前视野的底图和已启用的标记批次完成，避免分批加载期间保存缺少标记的图片。
